## 1. Section 13.3.1, "Unblending the liens" table: middle row divides $K_1 = 934$ by the 2016 face
- Note: the "first-lien second-out only" row builds $K_1 = 934$ from June 2020 holdings ($992 \times 0.74$) but divides by the 2016 first-lien face of 1,950 (47.9); on the June 2020 face of 1,887 it reads 49.5, and the sentence below should say "between five and twelve."
- Recomputation (python3): 992 x 0.74 = 734.08, so $K_1 = 200 + 734 = 934$. 934/1,950 = 47.90; 934/1,887 = 49.50. Other rows: 1,075/2,400 = 44.79 (44.8) and 1,075/1,887 = 56.97 (57.0), so the third row and the blend both already use the June 2020 first-lien face / blended face correctly. Gaps against the 44.8 blend: 49.5 - 44.8 = 4.7 (five) and 57.0 - 44.8 = 12.2 (twelve); the old row gave 3.1 (three). The strike 934 is June 2020 money, so its pre-deal slice must be divided by the June 2020 face the text itself calls the first lien outstanding, as the third row does.
- Ruling: note right (fixed).
- Chapter (§13.3.1 table): "| Unblended, first-lien second-out only | 934 | 1,950 (2016 first-lien face) | 47.9 |" -> "| Unblended, first-lien second-out only | 934 | 1,887 (June 2020 first-lien face) | 49.5 |"

- Solution (Z.13.1): quotes none of 47.9, 1,950 or "three"; no text change. NOTE paragraph deleted.
