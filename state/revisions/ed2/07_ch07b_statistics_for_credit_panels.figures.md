## Flags for the orchestrator (not fixed: outside the figure edit's remit)
1. 7-B.8 says the monthly grid "behaves like ... 2Phi(-1.37) approx 17.1%" (the Broadie-Glasserman-Kou continuity correction) and exercise 5 says "the grid converges to about 17.1%", while the chapter's own acceptance test and this figure's simulation give 17.6-17.7%. The BGK shift is an approximation; the exact grid value is 17.7%, so the 5.9-point gap in the exercise is 5.4 points. Figure 7-B.5 quotes 5.4 points.
2. The Bohn-Stein extraction in 7-B.6 says "about half of the time ... we would mistake the default probability for 20 bps when it was actually 200 bps". Under the stated one-factor model (rho = 0.25, PD 2%) the limiting default rate is below 20 bp only 19% of the time (36% below 50 bp), and its median is 89 bp. The quote may refer to a different tolerance or a multiyear setup; the figure set deliberately does not draw this case.
3. The build prints "Failed to find font weight semibold for DejaVu Sans, now using 700" for every figure: style.py sets axes.titleweight to "semibold". Harmless (titles render bold), but style.py could use "bold".
